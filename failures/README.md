## Reading a case table

- **certain** — the tool ran `ranting`'s own inflection and compared it against a rule that is a function of spelling alone. No judgement about the corpus involved.
- **attested** — as *certain*, and the corpus independently writes the corrected form. The strongest evidence available without a lexicon.
- **heuristic** — rests on the determiner cue in `corpus.rs` being right about this word's part of speech. Read the quoted sentences before acting.

There is no part-of-speech tagger here. A word counts as a noun when a determiner or a numeral preceded it — conservative, so the counts under-report rather than invent.
