This library is for deriving the [`Ranting`][Ranting] trait and the macros that inflect words within placeholders: `say!()`, `say_with!()`, `ack!()`, `nay!()`, `heed!()`, `ask!()`, `#[derive(Heed)]`, and the trait-object helpers `boxed_ranting_trait!()`/`ref_ranting_trait!()`.

You normally do not depend on this crate directly — `ranting` re-exports every macro above, so `use ranting::*;` is enough.
